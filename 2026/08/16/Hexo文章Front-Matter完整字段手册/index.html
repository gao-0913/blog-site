Hexo文章Front-Matter完整字段手册

2026-08-16

Hexo教程, 建站笔记

使用规则：不需要的字段直接删除，不会报错。

字段总览详解

1. title 文章标题【必填】

作用：定义文章标题、浏览器网页标题。

说明：不能为空，每篇文章必须配置。

2. date 发布日期【必填】

作用：控制文章排序、归档时间线。

格式标准：年-月-日 时:分:秒

3. tags 文章标签【可选】

作用：文章轻量化标签，支持多个标签，用于标签页面归类。

4. categories 文章分类【可选】

作用：文章大类划分，推荐一篇文章只设置一个分类。

5. abstract 首页摘要【美化推荐】

作用：自定义博客首页展示简介，替代系统自动截取文本，显示效果更好，Ayer 主题完美兼容。

6. top 文章置顶【进阶功能】

作用：将文章置顶在首页上方；数值越大，排序越靠前。

前置条件：安装插件 hexo-generator-index-pin-top

7. password 文章加密【私密文章专用】

作用：开启文章密码解锁访问。

前置条件：安装插件 hexo-blog-encrypt

8. theme 加密解锁动画【加密配套】

作用：设置密码解锁后的过渡动画

可选：default / xray / blink / flip / shrink / surge / up / wave

9. comments 评论开关【可选】

作用：单独控制单篇文章是否开启评论

true = 开启，false = 关闭

10. author 独立作者【可选】

作用：单独为当前文章设置作者，覆盖网站全局作者信息。

11. description SEO 页面描述【收录优化】

作用：搜索引擎抓取的页面简介，利于网页收录。

12. keywords SEO 关键词【收录优化】

作用：给搜索引擎提供关键词，提升搜索匹配效果，逗号隔开。

13. 阅读更多

作用：长文章折叠
在要折叠的地方输入

💡 使用小贴士

1、基础必写字段：title、date

2、归类使用：tags（多标签）、categories（单分类）

3、页面美化：abstract

4、首页置顶：top: 数字

5、私密文章：password + theme

6、评论管控：comments

7、搜索引擎优化：description、keywords
